# 가정·합성 데이터

원본(`01_참가자_배포용/04_원본데이터`)은 수정하지 않습니다. 참가자가 정한 가정, 새로 만든 매핑, 합성 데이터, 모의 회신은 모두 이 폴더에 둡니다(A05 6항).

## 파일마다 남길 것

| 항목 | 설명 |
|---|---|
| 식별자 | 행마다 고유 ID (예: `ASM-001`) |
| 구분 | `assumption`(가정) · `mapping`(매핑) · `synthetic`(합성 관측값) · `mock_reply`(모의 회신) |
| 적용 시점 | 이 값이 유효한 날짜·기간 |
| 원본 연결 | 근거가 된 원본 파일과 행 ID |
| 생성 이유 | 왜 필요했는지, 원본에 무엇이 없었는지 |

CSV 는 원본과 같이 `|` 로 구분하고 UTF-8 로 저장합니다.
